# 🛰️ GeoPulse — Interactive GIS Map Engine

> 🌍 A clean, lightweight, and interactive web mapping application powered by open cartographic standards and open-source geospatial data. Designed to deliver high-resolution satellite imagery, topographic relief, and street maps with zero proprietary API key requirements or hidden costs. 🚀✨

## 🌟 Key Features

- 🗺️ **Multiple Map Layers (XYZ Raster)**:
  - **Satellite HD (Esri)**: Global high-resolution aerial and satellite imagery with boundary overlays.
  - **Street Map (OpenStreetMap)**: Detailed urban grid, road networks, and worldwide points of interest.
  - **Topography (OpenTopoMap)**: High-altitude contour lines and elevation hillshading derived from SRTM data.
- 🌓 **Dark & Light Mode**: Instant theme switching tailored for day or night operations with high-contrast palette support.
- 🌐 **Bilingual Support**: Real-time language toggling between Spanish (ES) and English (EN).
- 🔍 **Open Geocoding Search**: Fast global search for cities, regions, and landmarks powered by the open Nominatim engine.
- 📍 **Live GPS Geolocation**: One-click centering on user position with an animated radar marker using the browser Geolocation API.
- 🎛️ **Navigation Controls**: Floating control panel featuring smooth zoom, view reset, fullscreen mode, and live coordinate HUD.
- 💸 **100% Free & Open**: No credit cards, commercial billing accounts, or proprietary mapping keys required.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Local Setup

```bash
# 1. Clone the repository
git clone https://github.com/your-username/geopulse.git

# 2. Navigate to project directory
cd geopulse

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production
npm run build
```
